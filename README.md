# Library Management System in C++

## 📚 About the Project
The Library Management System is a mini project developed in C++ as part of Object-Oriented Concepts and Programming (OOCP). It is designed to simplify basic library operations and demonstrate the practical implementation of object-oriented programming concepts.

## ✨ Features
- Add and manage library books
- Display available books
- Search for books
- Issue books to students
- Return issued books
- Manage basic library records
- Menu-driven console interface

## 🛠️ Technologies Used
- **Programming Language:** C++
- **Concepts:** Classes, Objects, Functions, Conditional Statements, Loops, and File Handling (if implemented)
- **IDE:** Visual Studio / Visual Studio Code

## 🎯 Project Objectives
- Understand the fundamentals of C++ programming.
- Apply object-oriented programming concepts to a real-world problem.
- Simplify basic book management operations.
- Develop practical mini-project experience.

## ▶️ How to Run
1. Clone or download this repository.
2. Open the project in Visual Studio or another C++ IDE.
3. Compile the C++ source code.
4. Run the generated program.
5. Follow the on-screen menu to manage library operations.

## 🎓 Academic Purpose
This project is developed for educational purposes as an OOCP mini project. It helps students understand how C++ can be used to build a basic management system.
